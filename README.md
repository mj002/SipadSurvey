"# SipadSurvey" 
1. pip install selenium==4.27.1
2. run survey.py
note: You can use dist/survey.exe.
note 2: Ensure Google Chrome is installed on your device.
note 3: You can minimize this application and continue using your device while it runs.
note 4: For support, contact https://t.me/Shlheidari.
note 5: Keep a compatible chromedriver.exe beside the app if desired. Otherwise, the app downloads a compatible driver from Huawei Cloud or npmmirror. Google Chrome is never downloaded.
note 6: Downloaded drivers are cached in chromedriver_cache/<version>/ beside survey.py (or beside survey.exe when packaged) and reused on later runs.
note 7: Earlier versions cached drivers in %LOCALAPPDATA%\SipadSurvey\chromedriver. The current version no longer uses that folder. You can delete it to free up disk space after closing any older versions of the app.
